# ADR 0033 — free search is an opt-in dimension

- Status: accepted
- Date: 2026-09-08

The operator wants useful improvements over repeated cheap Luna runs. A narrow lens can end
an otherwise useful pass when its particular surface is quiet. Add `general` to the existing
dimension mechanism rather than a second search-mode setting. Categories guide attention;
they do not restrict eligible findings. The default dimension set remains unchanged.

General search checks at least three areas before an empty result, or all available areas in
a smaller repo. It retains the generic invariant receipt and every existing ship gate. Its
coverage is recorded as `general`, so it cannot falsely mark a security or UI lens serviced.

Recent validated scans and terminal decisions are bounded prompt context for choosing fresh
work, not current-code proof. Empty results remain valid; branch and time caps remain limits,
not quotas the model must fill. The initial ten-branch Luna/high pilot is judged by GPT-6
review and accepted branches. Increased yield or quality is a hypothesis, not a measured result.
